# Packages

This folder contains the reusable SDK packages.

- [core/README.md](core/README.md) is the framework-free part of the SDK.
- [symfony-bundle/README.md](symfony-bundle/README.md) wires the core package into Symfony.

If you are new to the repo, read this folder after the root [README.md](../README.md).

For technical boundaries and maintenance notes, see [AGENTS.md](AGENTS.md).
